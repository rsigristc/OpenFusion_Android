# Contributing

Bug reports, device compatibility results, documentation corrections and code contributions are
welcome.

## Before opening a change

1. Read `README.md`, `NOTICE` and `docs/BUILDING.md`.
2. Base changes on the pinned Winlator revision documented in the repository.
3. Keep project-added files in `android-overlay/`.
4. Express changes to existing Winlator files as a normal Git patch in `patches/`.
5. Do not commit APKs, keystores, passwords, tokens or downloaded game files.
6. Include a clear explanation and the devices/configurations used for testing.

Contributions to this derivative are accepted under LGPL-2.1-or-later. By submitting a
contribution, you confirm that you have the right to provide it under those terms.

Security-sensitive reports that would expose credentials or a practical exploit should not
include secrets or personal data in a public issue. Open a minimal GitHub issue requesting a
private contact channel.
